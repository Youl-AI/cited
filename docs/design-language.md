## 0. 하드 룰 — 실측 숫자

리뉴얼 이후 남은 유일한 절대 규칙이다. 화면의 모든 수치·신뢰구간·답변 원문·질의는
**실제 데이터**여야 한다. 가짜 고객 로고·후기·지표를 만들지 않는다.

Cited가 파는 것은 숫자가 아니라 "그 숫자를 얼마나 믿어도 되는가"다.

- **점추정 단독 노출은 거짓말이다.** 큰 숫자 옆에는 반드시 Wilson 구간을
  붙인다 (`formatInterval`). 리포트 요약 카드·PDF 표지와 같은 규칙.
- **구간이 겹치면 ▲▼를 쓰지 않는다.** 변화 판정은 `judgeChange` 하나로만
  한다. 화면이 점추정끼리 따로 비교해 화살표를 그리면 안 된다.
- **"측정 없음"과 "측정했는데 0%"를 가른다.** `Interval.n === 0`이 판별
  기준이다 (`metrics.ts` 상단 주석). n=0을 "0% ~ 100%"로 그리지 않는다.
- **조건이 다르면 비교하지 않는다.** 엔진 구성이 다른 회차, 경쟁사 집합이
  다른 구간의 SoV — `incomparable`은 숨기지 말고 "비교하지 않는 이유"를 쓴다.

## 1. 표면 — 어디가 다크이고 어디가 라이트인가

- **마케팅(랜딩·요금제·무료진단 신청) = 다크.** 라우트 레이아웃이
  `.surface-dark`로 감싼다. 래퍼는 `min-h-dvh`여야 한다 — body는 라이트다.
- **앱(대시보드·온보딩·회차상세·리포트·auth) = 라이트.** `:root` 토큰 그대로.
- **`audit/[id]` 리포트는 라이트다.** 신청 흐름(`audit/new`·`requested`)이
  마케팅 표면인 것과 갈린다 — 리포트는 납품물이고 인쇄된다.
- **페이지 중간에서 테마를 뒤집지 않는다.** 다크↔라이트 경계는 라우트 단위다.
- `.dark` 전역 토글은 만들지 않는다.

## 2. mono는 계측값이다

- **sans는 말, mono는 계측값.** 언급률·구간·날짜·개수·엔진 이름·도메인·표기는
  전부 `font-mono tabular-nums`. 사람이 쓴 말(설명·가이드·버튼)은 sans.
  숫자는 `Metric` 패턴(`<span className="font-mono tabular-nums">`)을 통과시킨다.
- 표 안의 숫자는 전역 `table { font-variant-numeric: tabular-nums }`가 받는다.
- 이 규칙은 스킬 권한 밖이다 — 서체를 어떻게 바꾸든 계측값은 고정폭이다.
  자릿수가 흔들리면 사람이 수치를 비교할 수 없다.

## 3. 색의 뜻 (값이 아니라 뜻)

값은 `globals.css`가 정하고 taste 스킬이 재조율할 수 있다. 바뀌면 안 되는 것은
아래 뜻이다.

- **지표 상태 5색은 채우기 전용,** 텍스트·아이콘은 `-fg` 짝을 쓴다.
  `text-metric-up` 같은 조합은 금지 — `text-metric-up-fg`. 예외 하나:
  `--color-ci-band`는 면으로만 쓰여 `-fg` 짝이 없다 — 띠 위에 글자를 올릴 때는
  `--foreground`를 쓴다.
- **회색(`metric-flat`)의 뜻은 "변화 없음(측정 범위 내)" 하나뿐이다.**
  회색 램프를 다른 뜻(강도·순서)으로 재사용하지 않는다.
- **상승은 초록계·하락은 빨강계·변화없음은 무채색.** 상승과 하락은 명도가
  같아야 한다 — 한쪽만 무거워 보이면 판정이 편향된다.
- **엔진 계열색은 이름으로 쓴다:** `--color-engine-chatgpt`(청록) ·
  `--color-engine-gemini`(보라) · `--color-engine-naver`(자홍) ·
  `--color-engine-google`(진청록). `google_aio` → `--color-engine-google`.
  면·선 전용(3:1 기준) — 엔진 이름 글자는 `--foreground`로 쓰고 색은 옆에
  스와치(●)로 붙인다.
- **gemini와 google은 휘도가 가깝다.** 색만으로 가르지 않는다 — 마커 모양을
  함께 단다: chatgpt=원, gemini=사각, naver=마름모, google=삼각.
- **같은 뜻은 두 표면에서 같은 색상각을 쓴다.** `.surface-dark`는 지표·엔진
  색을 다시 선언하지만 **색상각은 그대로 두고 명도만 뒤집는다**(라이트에서는
  `-fg`가 더 어둡고, 다크에서는 더 밝다). 다크에서 새 색을 고르지 않는다.
- 브랜드색(`--primary`)은 "불확실성의 색" — 신뢰구간 띠의 진한 쪽. UI 크롬과
  강조에 쓰고 지표 방향에는 쓰지 않는다. 액센트는 표면당 이것 하나다.
- 시스템의 빨강은 하나다: 지표 하락 = 파괴적 동작 = `--destructive`와 동계.

## 4. 데이터 컴포넌트 문법

- **IntervalBar** (`src/components/interval-bar.tsx`): 회색 트랙 +
  `bg-ci-band` 구간 띠 + `bg-primary` 2px 점추정 눈금.
  `role="img"` + `aria-label="신뢰구간 X% ~ Y%"`. 모든 단일 구간 표시는 이걸 쓴다.
- **헤드라인 카드:** mono 점추정 + 옆에 mono 구간 + 아래 IntervalBar.
  리포트 요약 카드와 같은 문법. (크기·간격은 스킬 권한.)
- **판정은 문장으로 쓴다**(`changeSentence`). 색은 `-fg` 짝.
- **빈 상태는 방향을 준다.** "없습니다"로 끝내지 않는다 — 다음에 무엇이
  일어나는지("첫 측정이 끝나면 점이 하나 찍힙니다")를 쓴다.

## 5. 차트 렌더 로직 (불변)

리뉴얼은 차트의 **스타일**을 격상하되 **무엇을 그리는가**는 바꾸지 않는다.
데이터 표현을 바꾸면 조작이 된다. 의존성도 추가하지 않는다 — 수제 SVG.

### 5.1 추이 차트 (회차별 언급률)

- **점 + 오차 밴드.** 회차마다 점추정 점을 찍고, lower~upper를 잇는
  반투명 밴드(계열색)를 **반드시 함께** 그린다. 점만 찍고 구간을 감추는 것은
  금지. 연결선은 보조다.
- Y축은 0%~100% 고정, 눈금 0·50·100. X축은 회차 날짜(`MM.DD`, mono).
- **엔진별 토글:** 전체(=`citedRate`, `--primary`) / 엔진별(`byEngine`,
  엔진 계열색 + 마커 모양).
- **끊는 규칙:** `comparableWithPrev === false`(엔진·질의 집합·판정기 버전이
  바뀐 구간) 또는 `runsSkippedBefore > 0`(측정이 빠진 구간)이면 그 점을 직전
  점과 선분·밴드로 잇지 않고, 차트 캡션에 끊긴 이유를 쓴다 — 말없이 끊긴
  선은 버그로 읽힌다.
- 점 1개뿐이면 밴드는 세로 띠로 그린다 — "구간이 넓다"가 첫 화면의 정직한
  인상이어야 한다.
- 각 점은 `<title>`로 `날짜 · 점추정 (구간) · k/n`을 노출하고, svg 루트는
  `role="img"` + 최신 값 요약 aria-label.

### 5.2 질문별 히트맵 (질의 × 회차)

- 행 = **최신 회차의 `byQuery` 순서**(언급률 낮은 질문이 위 — "어느 질문에서
  비는가"가 가장 실행 가능한 정보라서다). `buildHeatmap`이 이 순서로 주므로
  화면에서 다시 정렬하지 않는다. 열 = 회차(최근 8회, 오래된 → 최신), 셀 =
  그 회차의 질의별 언급률(`byQuery`).
- **셀 채움:** `color-mix(in oklab, var(--primary) P%, transparent)`,
  `P = round(6 + 74 × point)` — 6%(0%)에서 80%(100%)까지. 브랜드색 단색
  램프인 이유: 히트맵의 값은 방향(좋다/나쁘다)이 아니라 강도이고, 상태색
  (초록/빨강)을 쓰면 "질문별 오차 넓은 1회 측정"에 방향 판정을 입히게 된다.
- **셀 텍스트:** `k/n` (mono). 채움이 진한 셀(P ≥ 50)은 글자를
  `--primary-foreground`로. 퍼센트가 아니라 k/n을 쓰는 이유: 분모가 곧
  오차의 크기라서다.
- 해당 회차에 그 질의가 없으면(질의 변경 전 회차) 셀은 `—` + 배경 없음 +
  `aria-label="측정 없음"`.
- 셀 `<title>`: `질의 · 회차 날짜 · 점추정 (구간)`.

### 5.3 점유율(SoV) 추이

- 추이 차트와 같은 점+밴드 문법, 색은 `--primary`.
- `shareOfVoice.n === 0`인 회차는 그리지 않는다.
- 끊는 규칙은 추이 차트와 같다. 단 SoV의 `comparableWithPrev`는 추이가 보는
  셋(엔진·질의 집합·판정기 버전) **위에 경쟁사 집합까지** 본다.
- **경쟁사 집합이 직전과 다른 구간**에는 추가로 차트 아래에 고정 문구를 쓴다:
  "경쟁사 설정이 바뀐 구간은 이전과 비교하지 않습니다 —
  분모가 달라지면 점유율은 설정 변경만으로도 움직입니다."
- 분모(등록 경쟁사 목록)를 차트 옆에 항상 표기한다.

## 6. 모션이 데이터에 하면 안 되는 것

지속시간·이징·연출 강도는 스킬 권한이고 토큰(`--motion-*`·`--ease-*`)이 값을
가진다. 여기 남는 것은 **데이터의 정직성을 해치는 모션**뿐이다.

- **숫자를 굴리지 않는다(count-up 금지).** 계측값은 튀지 않고 제자리에 있어야
  한다. 지나간 중간값들은 측정된 적이 없는 숫자다.
- **차트에 스크롤 하이재킹을 걸지 않는다.** 드로우인·호버 툴팁·크로스헤어까지.
  스크롤 위치가 데이터를 결정하면 안 된다.
- **오차 밴드는 점보다 먼저 또는 같이 나타난다.** 점을 먼저 보여 주고 밴드를
  나중에 붙이는 연출은 "확정값처럼 보였다가 흐려지는" 인상을 준다.
- **`prefers-reduced-motion: reduce`면 전부 끝난 상태로 시작한다.**
  `globals.css`의 전역 킬 스위치가 duration·delay·iteration을 모두 중화한다.
  GSAP·Motion은 여기에 더해 각자 `useReducedMotion` 가드를 단다.
- 초기 상태(`opacity: 0` 등)를 컴포넌트 클래스에 직접 박지 않는다 —
  애니메이션이 죽은 환경에서 요소가 영영 안 보인다.

## 7. 인쇄 (`audit/[id]` 리포트 PDF)

유료 납품물이다. 리뉴얼 후에도 회귀가 없어야 한다.

- 리포트 라우트는 **라이트 표면**이다. `.surface-dark`에 물리면 안 된다.
- `body`의 `print:bg-white` 유지 — 화면용 종이색(`--background`)은 PDF 여백의
  순백과 어긋나 장마다 회색 이음선을 만든다(실측).
- 인쇄 매체는 애니메이션 속성을 받지 않는다. 모션 클래스가 최종 상태로 찍히는지
  확인한다(초기 상태를 클래스에 박지 말라는 §6과 같은 이유).
- 변경 후 `pnpm audit:pdf` 1회 실측 검증.
