# 2단계 전 구간 실측 (2026-07-30)

`pnpm measure`로 엔진 호출 → 1차 매칭 → 2차 판정 → 지표 집계 → 인용 출처까지
실제 API로 한 번에 돌린 결과.

## 가장 중요한 발견 — 엔진이 브랜드명을 서로 다른 문자로 쓴다

같은 질의, 같은 시스템 프롬프트인데:

| 엔진 | 아식스 | ASICS | 나이키 | Nike |
| --- | --- | --- | --- | --- |
| ChatGPT (`gpt-5-mini`) | ✗ | ✓ | ✗ | ✓ |
| Gemini (`gemini-3.5-flash-lite`) | ✓ | ✗ | ✓ | ✗ |

ChatGPT는 `ASICS GEL-CUMULUS 28`, Gemini는 `아식스 노바블라스트`로 쓴다.
**한 쪽도 예외가 없었다.**

측정에 미치는 영향:

```
별칭 없음:  ChatGPT  0%   Gemini 100%   전체 50%
별칭 있음:  ChatGPT 50%   Gemini 100%   전체 75%
```

**영문 별칭 없이 한글 브랜드명만 넘기면 ChatGPT 언급률이 구조적으로 0%가 된다.**
고객에게 "ChatGPT에서는 한 번도 안 나옵니다"라고 보고하게 되는데, 그건 측정
결과가 아니라 우리 버그다. 엔진 비교가 통째로 거짓이 된다.

따라서:

- **별칭 생성은 선택 사항이 아니라 ChatGPT 엔진의 전제 조건이다.**
  4단계 온보딩의 `generateAliases`는 반드시 **한글·영문 양쪽**을 만들어야 한다.
  3단계 무료 진단도 같다 — 브랜드명만 받아서 돌리면 안 된다.
- **경쟁사도 같은 문제를 겪는다.** 이번 측정에서 경쟁사에 별칭을 주지 않아
  나이키가 ChatGPT 답변에서 과소 계상됐다(`Nike`로만 등장). 경쟁사 별칭도
  생성해야 한다.
- 제품명도 별칭에 넣을 값어치가 있다 — `젤카야노`, `노바블라스트`,
  `페가수스`처럼 브랜드명 없이 제품명만 나오는 답변이 많다.

## 측정 실측치

`pnpm measure --samples 1 --aliases "ASICS,젤카야노,…" --competitors "나이키,뉴발란스,호카" --domains asics.com "아식스" <질의 2개>`

| 항목 | 값 |
| --- | --- |
| 답변 | 4건 (질의 2 × 엔진 2 × 샘플 1) |
| Cited Rate | 75% (30% ~ 95%) |
| 엔진별 | ChatGPT 50% · Gemini 100% |
| 1차 통과율 | **50%** (후보 16 → 통과 8) |
| 2차 호출 | 8건, 미판정 0 |
| 원가 | 엔진 162원 + 판정 14원 = 176원 |
| 측정 1회당 | **44원** |
| 판정 비중 | **8%** |

### 1차 통과율이 설계 가정보다 높다

설계 문서는 1차에서 70~80% 탈락을 가정했다. 실제는 **50% 통과**다.
경쟁사를 등록하면 등록된 브랜드 중 절반가량이 답변에 실제로 등장하기 때문이다.

원가 문제로는 이어지지 않았다 — 판정 비중이 8%에 그쳤다. 판정기(Haiku 4.5)가
수집 엔진보다 두 자릿수 배 싸기 때문이다. **1차 매칭을 좁혀서 판정 원가를
아낄 이유가 없다**는 Task 9의 판단(재현율 우선)이 여기서도 확인됐다.

### 엔진 간 격차가 크다

같은 브랜드가 ChatGPT 50% / Gemini 100%다. 별칭을 맞춘 뒤에도 이만큼 벌어진다.
표본이 2건씩이라 구간이 넓지만(ChatGPT 9~91%), 격차 자체는 리포트에서 다뤄야
할 정보다 — "어느 엔진에서 약한가"가 조치를 가른다.

## 인용 출처 실측

답변 4개에서 도메인 17개. 우리 사이트(`asics.com`)는 **0회 인용**.

영문 리뷰 사이트가 강하게 반복된다: `runnersworld.com`, `rtings.com`,
`runrepeat.com`, `runningwarehouse.com`, `outdoorgearlab.com`.
한국 출처: `tistory.com`(2건), `danawa.com`, `footsell.com`, `geniet.co.kr`,
`runable.me`, `runningwikii.com`.

`tistory.com`이 4개 중 2개에 걸렸다. 30질의로 늘리면 반복 출처가 더 분명히
갈린다 — 그게 크몽 리포트의 실행 목록이 된다.
