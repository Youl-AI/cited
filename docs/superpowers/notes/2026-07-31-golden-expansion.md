# 골드 라벨 확장 — 새 업종 템플릿 (2026-07-31)

Task 9. 새 업종 템플릿(Task 2)의 질의로 실제 답변을 수집해 골드셋을
지역형·신규 업종으로 넓힌다. 기존 골드셋은 gemini 단일 엔진·구질의 40답변
200라벨이었다 — 이번에 **chatgpt 답변이 처음 들어간다.**

## Step 1 — 수집 (완료)

`scripts/label-subjects.mts`에 세트 2개 추가. 질의는 손으로 쓰지 않고
`generateAuditQueries()`에서 뽑았다 — 제품이 실제로 던지는 질의 그대로다.

| 세트 | 업종 템플릿 | 질의 | 브랜드(판정 대상) |
| --- | --- | --- | --- |
| `pilates-suwon` | 필라테스·요가 (지역형, 지역=수원) | 템플릿 3개 | 리본요가 · 클로바필라테스 · 더센터오브필라테스 |
| `finance` | 금융 (전국형) | 템플릿 3개 | 토스 · 카카오뱅크 · 카카오페이 · 뱅크샐러드 · 케이뱅크 |

수집: 질의 6개 × 엔진 2개(gemini, chatgpt) = **답변 12건 → 라벨 후보 48건**
(필라테스 6×3 + 금융 6×5). 전체 라벨 풀은 200 → 248건.

### 원가 실측

| 실행 | 답변 | 원가 |
| --- | --- | --- |
| gemini 6건 | 6 | 204원 |
| chatgpt 6건 | 6 | 243원 |
| chatgpt 재수집 1건 (아래 참고) | 1 | 24원 |
| **합계** | **12 (유효)** | **471원** |

### 수집 중 관찰 (라벨링·Step 3 때 참고)

- **chatgpt 1건 폐기·재수집**: "초보자가 쓰기 좋은 투자 앱 추천해줘"의 첫
  응답이 `(잠깐 정보를 확인합니다...)` 17자 스텁이었다. 후보에서 지우고
  같은 질의를 다시 수집했다(24원). 스텁 5라벨은 판정기 검증에 아무 정보가
  없다.
- **chatgpt 금융 답변은 미국 서비스 중심**이다(Zelle, Wise, Fidelity,
  Betterment…). 한국 브랜드가 거의 안 나와 **부정 라벨 공급원**이 된다.
  제품 관점에서도 시사점: 한국어 질의라도 chatgpt는 국내 금융 브랜드
  언급률이 gemini보다 훨씬 낮게 측정될 수 있다.
- **지역형 답변은 실제 상호를 잘 낸다**(양 엔진 모두). 필라테스 브랜드는
  답변이 실제로 언급한 상호 중 웹에서 실존을 확인한 3곳만 골랐다:
  리본요가 수원점(rebornyoga.co.kr), 클로바필라테스 수원권선점,
  더센터오브필라테스 수원인계점. 양 엔진이 공통 언급한 '필라테스 루틴
  (광교)'은 실존을 웹에서 못 굳혀 뺐다(미국 검색엔진이라 국내 로컬 업체
  검증력이 약한 탓일 수 있다 — 네이버 지도로 확인되면 다음 확장 때 추가).
- **필라테스 3브랜드는 각각 6답변 중 1곳에만 등장**한다(예상 긍정 3/18).
  지역 상호의 희귀 언급 케이스 — beauty 세트와 같은 역할이다.

## Step 2 — 수동 라벨링 (운영자 작업, 완료)

`pnpm label`로 48건 라벨링 완료. `pnpm label --stats` 최종:
**라벨 248 / 248 (언급 105 · 미언급 143) · 답변 52 / 52 완료.**
신규 48건만 보면 언급 8 · 미언급 40 — 예상(~13 긍정)보다 부정 쏠림이 컸다.

### 라벨링 중 운영자 관찰

- **chatgpt 금융 답변의 미국 서비스 편중이 실제로 확인됐다** — 예상대로
  한국 브랜드 5개가 대부분 미언급(부정 라벨 다수). 원인은 API `web_search`에
  locale 신호가 없어서다. (조치는 별도 검토 중 — 여기는 관찰 사실만 기록.)

## Step 3 — 게이트 재실행 (완료)

```bash
pnpm test:golden
```

- [x] 라벨 248건 기준 recall ≥ 95% · precision ≥ 90% 유지 확인 —
      **3/3 통과** (2026-07-31, Duration 104.70s)
- recall/precision 정확값: **게이트 통과(임계 이상)** — vitest가 테스트 내
  console 요약을 출력에 남기지 않았고, 게이트 1회 실행마다 판정 API 원가가
  나가므로 숫자 채취용 재실행은 하지 않았다. 다음번 정기 실행 때 수치를
  여기 덧붙이면 된다.
- 미달 유형 기록: 해당 없음 (통과)

**해석**: 새로 들어간 어려운 케이스 — 지역 상호 희귀 언급(필라테스 3브랜드),
카카오뱅크/카카오페이 접두어 쌍, chatgpt 미국 편중 답변의 대량 부정 —
전부에서 판정기가 임계를 유지했다. 판정 프롬프트 수정 불필요.
