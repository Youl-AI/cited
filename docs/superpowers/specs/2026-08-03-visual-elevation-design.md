# 시각 격상 설계 — 계측 미학 v2 (프리미엄 패스)

2026-08-03 작성. 기준점은 `design-v1` 태그(= 4단계 병합 시점, 절제판).
**구현은 Task 12(실측 검증) 이후.** 이 문서는 방향과 규칙을 확정하는 설계다.

## 0. 문제 정의

design-v1은 "정직한 계측기" 컨셉을 규칙으로 완성했지만, 사용자 평가대로
**정적**이다 — 버튼을 눌러도, 화면이 떠도, 차트가 그려져도 아무 일도 일어나지
않는다. 프리미엄 제품의 인상은 규칙 준수가 아니라 **반응성**(내 행동에 화면이
답한다)과 **연출**(중요한 것이 중요하게 등장한다)에서 나온다.

원칙은 바꾸지 않는다: **깔끔함 유지 + 정직성 불변.** 움직임은 장식이 아니라
"계측기가 살아 있다"는 증거로만 쓴다. 좋은 실물 계측기는 바늘이 *움직여서*
신뢰를 준다 — 다만 튀지 않고, 감쇠(damping)를 갖고 정확히 멈춘다. 그것이
이 패스의 미학적 뼈대다: **감쇠 있는 정밀 기계.**

## 1. 프리미엄 웹사이트 효과 분석 — 무엇을 가져오고 무엇을 버리나

잘 만든 제품 사이트(Linear·Stripe·Vercel·Arc 류)에서 반복 관찰되는 효과를
분류하고, Cited의 계측 미학과 충돌 여부로 판정했다.

| # | 효과 | 관찰되는 형태 | 판정 | Cited 적용 |
|---|---|---|---|---|
| 1 | **등장 오케스트레이션** | 페이지 로드 시 요소들이 위계 순서로 스태거 등장 (fade+8~16px rise, 40~80ms 간격) | **채택** | 전 화면 공통 문법. 제목 → 계측값 → 보조 순서 = 정보 위계가 곧 등장 순서 |
| 2 | **스크롤 트리거 리빌** | 섹션이 뷰포트 진입 시 1회 등장 | **채택 (랜딩만)** | 앱 화면은 스크롤 리빌 금지 — 대시보드는 문서가 아니라 계기판이다 |
| 3 | **버튼 프레스 피드백** | active에서 scale(0.97~0.98) + 그림자 수축, 뗄 때 스프링 복귀 | **채택** | 전 버튼. "눌렀다"는 물리적 확인 — 계측기 버튼의 촉감 |
| 4 | **호버 리프트/글로우** | 카드 hover 시 translateY(-2px) + 그림자 확장, 보더 하이라이트 | **부분 채택** | 클릭 가능한 카드(회차 목록·브랜드 피커)만. 정보 표시용 카드는 안 움직인다 — 눌리는 것만 움직여야 어포던스가 정직하다 |
| 5 | **차트 드로우인** | 선이 왼→오로 그려지고(stroke-dashoffset) 면이 차오름 | **채택 + 정직 규칙 추가** | §4 참조. 단 **점과 구간 밴드는 반드시 동시 등장** — 점이 먼저 뜨면 찰나라도 "구간 없는 점추정"이라 §0 위반 |
| 6 | **숫자 카운트업** | 통계 숫자가 0에서 목표값까지 굴러 올라감 | **기각 (불변)** | 계측값은 굴리지 않는다 — 이미 §5 금지. 굴러가는 숫자는 전부 거짓 값을 경유한다. 이 금지 자체가 브랜드 스테이트먼트다 |
| 7 | **타이핑/스트리밍 연출** | 텍스트가 입력·생성되는 과정을 실시간처럼 재생 | **채택 — 시그니처** | §2 참조. Cited의 피사체가 곧 "AI가 답을 타이핑하는 장면"이다 — 남들에겐 장식이지만 우리에겐 제품 설명 그 자체 |
| 8 | **스켈레톤/셔머 로딩** | 로딩 중 자리 표시 + 흐르는 하이라이트 | **부분 채택** | 대시보드 서버 렌더 대기 구간만. 셔머 루프는 §5 루프 금지의 유일한 예외로 명문화 (로딩 = 상태 표시이지 장식이 아님) |
| 9 | **글래스모피즘/블러 헤더** | 스크롤 시 반투명 blur 헤더 | **채택 (소극적)** | 헤더 한 곳만. 남용하면 계측기가 아니라 유리 장난감이 된다 |
| 10 | **그레인/노이즈 텍스처** | 배경에 미세 노이즈로 "인쇄물" 질감 | **기각** | 계측값 가독이 최우선. 질감은 리포트 PDF의 영역 |
| 11 | **패럴랙스/3D 틸트** | 스크롤 시 배경 이동, 마우스 추적 기울임 | **기각** | 값이 움직이는 화면에서 배경까지 움직이면 신뢰가 죽는다 |
| 12 | **뷰 전환 연속성** | 페이지 이동 시 공유 요소가 이어짐 (View Transitions) | **채택 (2순위)** | 대시보드 → 회차 상세: 헤드라인 숫자가 이어지면 "같은 측정"이라는 사실이 모션으로 전달된다 |
| 13 | **커서 추적 스포트라이트** | 카드 위 마우스 위치 따라 라디얼 하이라이트 | **기각** | 유행 소모품. 3년 뒤 촌스러워질 것에 투자하지 않는다 |
| 14 | **정밀 그림자 계층** | 다층 box-shadow로 높이 위계 (1px 보더 + 근거리 + 원거리) | **채택** | 현재 그림자가 사실상 없음. 토큰 3단(`--elevation-1/2/3`)으로 통일 |
| 15 | **디스플레이 서체 히어로** | 랜딩 제목만 캐릭터 있는 서체 | **채택 (랜딩만)** | 앱은 현행 유지. 랜딩 히어로에만 한글 디스플레이 급 (예: 한 단계 무거운 웨이트 + 타이트 트래킹, 신규 서체 도입은 로딩 비용 검토 후) |

**요약 원칙:** 반응(3·4)과 등장(1·2·5·8)은 넣고, 배경·질감·시선 끌기(10·11·13)는
버린다. 움직임의 주인공은 언제나 **계측값과 그 신뢰구간**이다.

## 2. 시그니처 — 랜딩 히어로 "실측 재현"

한 곳에만 대담함을 쓴다(나머지는 전부 조용히). Cited가 파는 장면을 그대로
재생하는 히어로:

1. 검색창에 실제 측정 질의가 **타이핑**된다 ("강남 피부과 어디가 좋아?")
2. AI 답변이 **스트리밍**으로 흐른다 (실측 발췌 — 조작 금지, 실제 저장된 답변)
3. 답변 속 브랜드 언급이 **하이라이트**되며 카운터에 집계된다 (1건씩, 카운트업
   아님 — 개별 사건의 누적이라 정직)
4. 집계가 끝나면 **IntervalBar가 차오르며** "언급률 32% (구간 21~44%)"로 정착
5. 루프하지 않는다. 재생 버튼으로만 반복 (§5 루프 금지 유지)

이 60~90프레임이 "우리가 뭘 하는 회사인가"를 카피 없이 설명한다. 어떤 경쟁
GEO 서비스도 자기 측정 과정을 화면에서 재생하지 않는다 — 측정 과정을 보여줄
수 있다는 것 자체가 정직성의 증명이고, 그게 우리 차별점이다.

기술: 순수 CSS 키프레임 + 소량의 클라이언트 컴포넌트. 실측 데이터는 빌드
시점에 박제(개인정보·고객사명 없는 샘플 측정 1건을 시드로 준비).

## 3. 모션 시스템 v2 (design-language.md §5 개정안)

v1 규칙은 전부 유지하고 어휘를 추가한다. **개정은 이 스펙 승인 후
design-language.md에 반영** — 계약 문서를 어기는 게 아니라 진화시킨다.

### 3.1 토큰 (globals.css에 추가)

```css
--motion-micro: 120ms;      /* 호버·포커스·프레스 (v1 유지) */
--motion-enter: 200ms;      /* 요소 등장 (v1 유지) */
--motion-chart: 240ms;      /* 차트 상태 전환 (v1 유지) */
--motion-draw: 600ms;       /* 신설: 차트 최초 드로우인 상한 */
--motion-stagger: 50ms;     /* 신설: 등장 스태거 간격 */
--ease-out: cubic-bezier(0.2, 0, 0, 1);        /* v1 유지 */
--ease-spring: cubic-bezier(0.34, 1.4, 0.4, 1); /* 신설: 프레스 복귀 전용, 오버슈트 4% 이내 */
--elevation-1/2/3: (다층 그림자 3단 — 구현 계획에서 수치 확정)
```

### 3.2 새 규칙

- **등장 오케스트레이션**: 화면당 1회, 위계 순 스태거(제목 → 계측값 → 보조),
  총 연출 길이 600ms 이내. 재방문·리렌더에는 재생 안 함(세션 내 1회).
- **차트 드로우인**: 마운트 1회만. 선은 그리기, 밴드는 fade, **점+밴드 동시
  완성**(§0 위반 방지 — 점이 구간보다 먼저 완성되면 안 된다). 끊긴 세그먼트는
  세그먼트별 순차 등장 — 끊김 자체가 연출로 강조된다(정직성의 시각화).
  히트맵은 셀 스태거 fade(행 우선 — "못 나오는 질문"이 먼저 뜬다).
- **프레스 피드백**: `active:scale-[0.98]` + 그림자 수축, 복귀는 `--ease-spring`.
  스프링 오버슈트는 프레스 복귀에만 허용 — 데이터 요소에는 금지.
- **셔머 예외**: 로딩 스켈레톤의 셔머만 루프 허용 (로딩 상태 표시로 한정).
- **금지 유지**: 계측값 카운트업 금지 · 레이아웃 속성 애니메이션 금지 ·
  reduced-motion 전역 킬스위치 · 무한 장식 루프 금지 · 스크롤 리빌은 랜딩만.

### 3.3 §6 체크리스트 추가분

- [ ] 점이 구간 밴드보다 먼저 완성되는 드로우인
- [ ] 앱 화면(온보딩·대시보드)의 스크롤 트리거 리빌
- [ ] 정보 표시용(비클릭) 카드의 호버 리프트
- [ ] 스프링 이징의 데이터 요소 사용

## 4. 화면별 적용 계획

### 4.1 랜딩 + 요금제 (효과 최대 — 앞당겨진 리트로핏)

- 히어로 전면 재구성: §2 시그니처 + 디스플레이 조판 + 스크롤 리빌 섹션
- 계측 조건표·요금제 카드: elevation 토큰 + 호버(카드 전체가 링크일 때만)
- 헤더: 스크롤 시 blur + 축소
- CTA 버튼: 프레스 피드백 + 미세 그라데이션 (브랜드색 범위 내)

### 4.2 대시보드 (효과 = 데이터 연출)

- 최초 진입: 헤드라인 카드 → 추이 차트 드로우인 → 히트맵 셀 스태거 순 등장
- 추이/SoV: 세그먼트별 드로우인(끊김 강조), 엔진 토글은 현행 opacity 유지
- 호버 인터랙션 신설: 점 호버 시 크로스헤어 + 툴팁 카드(현행 `<title>`을
  시각 툴팁으로 승격 — `날짜 · 점추정 (구간) · k/n` 동일 내용)
- 히트맵 셀 호버: 스케일 없이 보더 하이라이트만 (셀 크기가 값이 아니므로)
- 회차 목록: 클릭 가능 행만 호버 리프트
- 로딩: 스켈레톤 + 셔머

### 4.3 온보딩 (효과 = 진행감)

- 단계 전환: 다음 단계가 오른쪽에서 슬라이드+페이드 (진행 방향의 시각화)
- 질의 에디터: 검증 통과 시 행에 체크 마이크로 애니메이션(120ms), AI 생성 중
  스트리밍 커서(생성이 실제로 스트리밍이므로 정직), 생성 완료 행 스태거 삽입
- **동결 확인 모달**: 이 패스에서 가장 공들일 마이크로 순간 — "동결"이 무거운
  행동임을 모션이 전달(버튼 홀드 또는 2단 확인 + 잠금 아이콘 정착 연출)
- 완료 화면: 다음 측정 예고에 등장 오케스트레이션

### 4.4 리포트 화면 (`/audit/[id]` · 회차 상세)

- 등장 오케스트레이션 + 드로우인만 적용 (구조 변경 없음)
- 이연됐던 `result-view.tsx:309` 경쟁사 배지 색을 이 패스에서 함께 수정
  (화면·PDF가 같이 뒤집히는 시점이 지금이다 — PDF는 print CSS라 모션 무관)
- shadcn 프리미티브(button/badge/tabs)의 `transition-all` → 명시적 속성 +
  `--ease-out`으로 교체 (§5 위반 백로그 해소)

## 5. 기술 결정

| 축 | 결정 | 근거 |
|---|---|---|
| 애니메이션 라이브러리 | **도입 안 함** — CSS transition/keyframes + IntersectionObserver + 소량 훅 | 수제 SVG 전례와 동일 원칙. framer-motion류는 이 절제 수준에 과잉이고 번들 비용 |
| 스크롤 리빌 | IntersectionObserver 커스텀 훅 1개 (`useRevealOnce`) | tw-animate-css가 이미 devDeps에 있음 — 키프레임 유틸로 활용 |
| 뷰 전환 | Next.js View Transitions (2순위, 브라우저 지원 확인 후) | 실패해도 일반 내비게이션으로 자연 강등 |
| 서체 | 신규 도입은 랜딩 히어로 1곳 한정 검토, 아니면 현행 웨이트 조합 | 한글 웹폰트 로딩 비용 큼 — FOUT가 프리미엄을 죽임 |
| API 비용 | **0원** (히어로 실측 재현은 저장된 샘플 박제) | |

## 6. 구현 순서 (Task 12 이후)

1. **P0 — 모션 시스템**: 토큰 + design-language §5 v2 반영 + 프레스/이징
   프리미티브 교체 (전 화면이 즉시 좋아지는 기반)
2. **P1 — 랜딩·요금제**: 시그니처 히어로 + 스크롤 리빌 + elevation (첫인상 최대 효과)
3. **P2 — 대시보드**: 드로우인 + 툴팁 + 스켈레톤 (실측 데이터 확보 후라 튜닝 정확)
4. **P3 — 온보딩·리포트**: 단계 전환 + 동결 연출 + 배지 리트로핏
5. 각 P마다 디자인 패스(§6 v2 체크리스트) + 브라우저 실물 확인

## 7. 성공 기준
