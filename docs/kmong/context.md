# 크몽 사업 컨텍스트 (세션 핸드오프용)

> 2026-07-31 작성. 다른 세션에서 크몽 관련 글쓰기(문안·메시지·FAQ·후기 대응)를
> 도울 때 이 파일 하나로 충분하도록 압축했다. 숫자·주장을 바꿔 쓰기 전에
> "사실 검증 소스"의 코드를 먼저 확인할 것 — **코드가 못 지키는 약속을 쓰면
> 분쟁이 된다** (실제로 리뷰에서 "답변 원문 60개 전부 드립니다" 초과 약속을
> 잡아 고쳤다. 실제 리포트는 발췌 최대 6건·600자 절단).

## 무엇을 파는가

ChatGPT·Gemini에게 실제 고객이 묻는 방식으로 질문을 던져 **브랜드가 답변에
언급되는 비율을 실측**해 주는 진단 리포트. cited.co.kr(GEO 모니터링 SaaS)의
1회성 상품화. 웹 구독은 미오픈 — 크몽이 현재 유일한 유료 채널.

| 티어 | 구성 | 정가 |
|---|---|---:|
| 무료 샘플 | 질문 3 × 1회 = 답변 6개 (문의 응대용) | 0원 |
| STANDARD | 질문 10 × 3회 × 2엔진 = 답변 60개 리포트 | 49,000원 |
| DELUXE ★주력 | + 운영자 개선 가이드 | 99,000원 |
| PREMIUM | + 4주 뒤 같은 질문 재측정·전후 비교 | 189,000원 |

- 오픈 할인: 첫 5~10건 (예: DELUXE 69,000) — **최종 숫자 미확정** (운영자 결정 대기)
- 환불(확정): 측정 착수(질문 동결) 전 전액 / 착수 후 불가 / 측정 실패·미발송 전액
- 납기: **질문 확정 후 영업일 2일** (실측 근거: 전 과정 11분 + 가이드 20~40분)

## 퍼널

크몽 문의 → 무료 샘플 배송(PDF) → 맘에 들면 DELUXE → 상위 옵션 PREMIUM.
무료 샘플 메시지에서 DELUXE 안내는 OK(크몽 상품이므로).

## 측정 사실 (문안에 쓸 수 있는 주장의 전부)

- 엔진: **ChatGPT·Gemini 2개뿐.** 네이버·Google AI 개요 미지원 — 정직하게 명시
- 질문 10개 = 업종 템플릿 3(무료 샘플과 동일 — 연속성) + 맞춤 7(LLM 후보 생성
  → 운영자 검수 → 고객 확인·수정 1회 → 영구 동결)
- 질문에 브랜드명·경쟁사명 **넣지 않음** — 코드가 거부(중립성). "저희를 아는지
  묻는 게 아니라 고객처럼 묻습니다"가 신뢰 포인트
- 언급률은 점이 아니라 **신뢰구간**으로 보고 (Wilson, 비대칭 — "N% ~ M%" 서식,
  ±로 쓰지 않는다). 1회 측정은 구간이 넓어 의미 없음 → 3회 반복이 상품 근거
- 전후 비교(PREMIUM): 구간이 겹치면 **"측정 오차 범위"라고 그대로 씀** —
  오르지 않았는데 올랐다고 보고하지 않는 것이 셀링 포인트
- 리포트 구성(PDF 9쪽): 표지(브랜드·측정 조건) → 언급률+구간 → 언급 점유율
  (경쟁사 최대 3 대비) → 질문별 결과 → 대표 AI 답변 원문 **발췌 최대 6건**
  (600자 절단) → AI가 읽는 출처(도메인별 인용, 우리 사이트 포함 여부) →
  (DELUXE+) 개선 가이드 → (PREMIUM) 전후 비교
- 60개 답변은 **전부 판정·집계에 사용** — 단 원문 전체 전달은 아님 (발췌 6건)
- 업종 커버리지 25종: 전국형 10(패션·화장품·식품·가전·교육·이커머스·앱
  서비스·여행숙박·금융·프랜차이즈) + 지역형 15(치과·피부과성형·한의원·
  동물병원·필라테스요가·헬스장·미용실네일·학원·변호사·세무사·인테리어·
  이사청소·식당카페·웨딩·부동산). **지역형은 지역 필수** — 없으면 시스템이
  실행 거부. 새 업종 추가는 ~10분 작업이라 "이 업종 되나요?" 문의에 유연

## 카피 원칙 (hard rule)

- **과장 금지**: "보장", "상위 노출", 확정적 개선 약속 금지. 측정 상품이지
  마법이 아님. 오히려 "노출을 보장하지 않습니다"가 문안에 명시돼 있음
- 1회 측정의 한계(AI 답변은 흔들린다 → 그래서 3회·구간) 명시
- 숫자는 그대로: "언급률 32% (구간 21~44%)". 0%면 0%라고 씀
- 하는 것/안 하는 것 구분: 백링크·사이트 수정·콘텐츠 제작은 범위 밖

## 납품 정책 (2026-07-31 결정 — 중요)

- **크몽 납품물은 PDF 하나뿐.** 웹 리포트 링크는 크몽 고객에게 절대 보내지
  않는다 — 사이트의 요금제·구독 유도에 노출되면 크몽 직거래 유도 정책 위반
  소지(계정 제재 리스크). PDF에서도 요금제 전환 섹션은 제거돼 있다
- 고객 이메일을 받지 않는다. 시스템 등록은 운영자 이메일로, 고객 접점은
  크몽 메시지 하나로 일원화
- 납품 메시지: PDF 첨부 + 한 줄 요약(숫자 그대로) + 구매확정 요청

## 운영 흐름 요약 (상세는 delivery-checklist.md)

무료: 정보 수신(브랜드·업종·지역) → audit:new --tier free → run --dry →
run 발송 → audit:pdf → 크몽 메시지(PDF+요약+DELUXE 안내). ~5분, 원가 ~470원.

유료: 발주 정보 수신 → audit:new → audit:queries --brief → 운영자 검수 →
**질문 초안을 고객에게 확인(수정 1회)** → --freeze → run --dry(지문 확인) →
(DELUXE+) 가이드 작성 → audit:guide → run 발송 → audit:pdf → 크몽 메시지.
~10분 + 가이드 20~40분, 원가 ~4,800원 (dry+발송 이중 측정 — 개선 예정).
PREMIUM은 4주 뒤 audit:remeasure(질문 자동 복제)로 2번째 납품.

## 리허설 실측 (2026-07-31, 실존 업체 리본요가·수원 필라테스 DELUXE)

접수→PDF 11분, 원가 4,798.9원, 막힘 0. 결과: 언급률 27%(17~39%), 경쟁사
대비 1위(16회), ChatGPT 13%·Gemini 40%(엔진별 출처 구성이 달라 격차 —
가이드의 부가가치 소재), 답변 60개 중 58개에 출처 인용, 도메인 65개.
LLM 질문 후보 7개 중 4개를 검수에서 교체(정보성 질문은 업체 추천이 안 나옴)
— "운영자 검수"가 실질임을 보여주는 사례.
