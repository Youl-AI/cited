# 크몽 자동응답 문안

> 2026-08-06 작성. `판매 관리 > 전문가 응답 관리 > 자동 응답`
> (`/seller/message-reaction-settings/auto-messages`)

## 이 기능이 실제로 무엇인가 (초판 오해 정정)

인사말 자동발송이 **아니다.** 의뢰인 메시지 화면에 뜨는 **질문 카드 목록**이다.
의뢰인이 질문을 누르면 미리 등록한 답변이 보인다.

초판에서 `문의 자동응답 / 주문 후 안내 / 영업시간 외` 3종으로 설계했던 것은
이 기능에 맞지 않아 폐기했다.

| 항목 | 실측값 |
|---|---|
| 질문 | **25자** |
| 답변 | **600자** |
| 최대 개수 | **5개** |
| 노출 | 등록과 별개로 **ON/OFF 토글**을 켜야 보인다 |
| 이모지 | 질문 앞에 하나 붙일 수 있다 (기본 ✅) |

**응답 지표와 무관하다.** 페이지에 명시돼 있다 — "자동응답은 메시지 응답률과
평균 응답시간에 영향을 미치지 않아요." 초판에서 "응답 지표를 방어한다"고 쓴
것은 틀렸다.

크몽이 추천 질문을 제시한다(작업과정 / 상담 가능 시간 / 수정 요청 방법).
우리는 쓰지 않았다 — 대행업 전제라 측정 상품과 맞지 않는다.

## 5개를 어떻게 골랐나

한도가 5개라 **상세페이지에서 못 막는 것 + 분쟁 소지가 큰 것** 순으로 잘랐다.

| # | 질문 | 채택 이유 |
|---|---|---|
| 1 | 무료로 먼저 받아볼 수 있나요? | 퍼널 핵심. 문의를 무료 진단으로 넘긴다 |
| 2 | 측정은 어떻게 하나요? | 가장 흔한 첫 질문 |
| 3 | 우리 업종도 되나요? | 지역 정보가 없으면 실행 자체가 막힌다 |
| 4 | 결과가 0%로 나오면요? | 사전 자격 판별 + 분쟁 예방 (§11 정책) |
| 5 | 최적화 작업도 해주시나요? | "작업 안 함"이 최대 오해 지점 |

**뺀 것과 이유**
- 어떤 AI로 측정하나요 — 상세 본문과 이미지에서 크게 다룬다
- 납기는 얼마나 걸리나요 — 패키지 작업일에 표시된다
- 환불 기준 — 크몽이 표준 환불 규정을 상품 페이지에 노출한다

뺀 3개의 문안도 아래에 남겨 둔다. 한도가 늘거나 교체가 필요할 때 쓴다.

## 등록한 5개

### 1. 무료로 먼저 받아볼 수 있나요?

```
구매 전에 무료 진단을 보내드립니다. 질문 3개를 만들어 ChatGPT와 제미나이에
실제로 물어보고, 받은 답변 6개를 정리해 PDF 리포트로 드립니다. 비용은 없습니다.

아래 3가지만 알려주시면 바로 시작합니다.
1. 브랜드명(상호)
2. 업종 (예: 필라테스, 치과, 패션, 이커머스)
3. 지역 - 지역 안에서 고객을 받는 업종만 (예: 강남, 수원 영통)

병원, 필라테스, 미용실, 학원처럼 지역 기반 업종은 지역이 꼭 필요합니다.
"수원 필라테스 어디가 좋아?"처럼 실제 고객이 묻는 방식으로 재기 때문입니다.

보통 하루 안에 리포트를 보내드립니다.
```

### 2. 측정은 어떻게 하나요?

```
실제 고객이 할 법한 질문 10개를 ChatGPT와 제미나이에 각각 3번씩, 총 60번
묻습니다. 답변 60개를 전부 판정하고 집계해 언급률을 내고, 오차 범위를 함께
드립니다.

AI는 같은 질문에도 매번 다르게 답합니다. 한 번 물어보고 나왔다고 하는 건
동전을 한 번 던져 놓고 확률을 말하는 셈이라, 질문마다 3번씩 반복합니다.

리포트에는 던진 질문 10개 전문과 AI 답변 원문 발췌를 실어, 무엇을 근거로
판정했는지 직접 확인하실 수 있게 합니다.
```

### 3. 우리 업종도 되나요?

```
지역 기반 업종(치과, 피부과, 한의원, 동물병원, 필라테스, 요가, 헬스장,
미용실, 학원, 변호사, 세무사, 인테리어, 식당, 카페, 웨딩, 부동산 등)과
전국 단위 업종(패션, 화장품, 식품, 가전, 이커머스, 앱 서비스, 여행숙박,
금융 등)을 다룹니다.

목록에 없는 업종도 문의 주시면 측정이 의미 있는지 먼저 답해 드립니다.

지역 안에서 고객을 받는 업종은 지역 정보가 반드시 필요합니다. 지역이 없으면
고객이 실제로 묻는 방식의 질문을 만들 수 없어 측정이 진행되지 않습니다.
```

### 4. 결과가 0%로 나오면요?

```
솔직하게 말씀드립니다. 신생 브랜드이거나 전국 단위 경쟁 시장이면 0%가 나올
가능성이 높습니다. 이미 알려진 큰 브랜드가 답변을 채우기 때문입니다.

반대로 지역 기반 업종은 0%가 아닌 경우가 많습니다. 후보가 수십 곳으로
좁아지기 때문입니다. 실제 측정 사례에서 수원의 한 필라테스 스튜디오는
언급률 27%(구간 17~39%)였습니다.

0%여도 리포트에 남는 것이 있습니다. AI가 그 질문에 답하며 인용한 사이트
목록, 어떤 질문이 업체 추천을 유발하는지, 답변을 채운 브랜드가 누구인지입니다.

무료 진단에서 0%가 확인되면 그대로 알려드립니다. 그때는 측정보다 콘텐츠가
먼저라고 말씀드리고, 개선 가이드가 붙는 상위 패키지는 권하지 않습니다.
```

### 5. 최적화 작업도 해주시나요?

```
아니요, 진단만 합니다. 백링크, 사이트 수정, 스키마 설치, 콘텐츠 제작은
범위 밖입니다.

DELUXE 이상의 개선 가이드는 무엇부터 손대야 하는지의 우선순위이지 대행
작업이 아닙니다.

측정과 작업을 한 곳이 하면 성적표를 스스로 매기는 셈이라 분리하는 게 맞다고
봅니다. 먼저 재보시고 필요하면 그때 작업하시면 됩니다.
```

## 예비 문안 (한도 초과로 미등록)

### 어떤 AI로 측정하나요?

```
ChatGPT와 구글 제미나이 2개입니다. 타사 AI 브리핑과 구글 AI 개요는 아직
지원하지 않습니다.

엔진 수가 적어 보일 수 있는데 두 가지 이유가 있습니다.

첫째, 이용자가 많은 두 서비스입니다. 오픈서베이 2026년 하반기 조사(검색
이용자 1,000명)에서 최근 3개월 내 이용 경험은 ChatGPT 58.1%, 제미나이
52.2%였습니다.

둘째, 엔진을 추가하는 것보다 같은 질문을 여러 번 묻는 쪽이 숫자를 정확하게
만듭니다. 질문마다 한 번씩만 물으면 엔진이 몇 개든 오차 범위를 계산할
근거가 없습니다.
```

### 납기는 얼마나 걸리나요?

```
질문 목록을 확정해 주신 시점부터 영업일 2일 이내에 PDF를 보내드립니다.
질문 초안은 발주 정보를 받은 뒤 보통 당일에서 1영업일 안에 보내드립니다.

PREMIUM은 4주 뒤 재측정까지 포함해 작업 기간이 28일입니다. 1차 리포트는
마찬가지로 영업일 2일 안에 먼저 보내드립니다.

급하시면 빠른 작업 옵션을 이용하실 수 있습니다.
```

### 환불 기준이 어떻게 되나요?

```
질문 목록 확정 전에는 전액 환불됩니다.

질문을 확정하면 AI 엔진 호출이 실제로 발생해 단순 변심 환불이 어렵습니다.
그래서 확정 전에 반드시 질문 초안을 보내드리고 확인을 받습니다.

납기를 지키지 못한 경우에는 전액 환불해 드립니다.

측정 결과의 숫자가 기대와 다르다는 이유의 환불은 어렵습니다. 현재 상태를
그대로 재는 측정 상품의 특성입니다.
```

## 제약 (등록 문안과 동일)

- 외부 링크·연락처·직거래 유도 금지 (페이지에 "직접결제 유도 시 서비스 이용
  제한" 명시)
- 금지어: `네이버` · `늘려` · `보장` → `타사` · `추가해` · `약속`
- 최상급 표현 금지

## 등록 완료 (2026-08-06)

`총 개수 5/5`, 노출 **ON**. 순서는 등록순이고 `순서 변경하기`로 조정할 수 있다.

```
1  ✅ 무료로 먼저 받아볼 수 있나요?
2  ✅ 측정은 어떻게 하나요?
3  ✅ 우리 업종도 되나요?
4  ✅ 결과가 0%로 나오면요?
5  ✅ 최적화 작업도 해주시나요?
```

1번이 첫 카드라 의뢰인이 처음 보는 것이 무료 진단 안내가 된다 — 의도한 배치다.

`%` 문자는 통과했다. 특수문자 제한은 **상품 제목에만** 적용되고 자동응답에는
없다.

## 폼 조작 메모 (다음 세션용)

- 첫 등록 버튼은 `등록하기`, **두 번째부터는 `추가하기`**다
- 제출하면 폼이 닫힌다. 같은 `추가하기` 버튼이 **닫힘 상태에서는 여는 역할**을
  하므로, 등록 루프는 `열기 → 입력 → 제출`로 짜야 한다
- 크몽 추천 질문 3개(작업과정 / 상담 가능 시간 / 수정 요청 방법)는 쓰지 않았다.
  대행업 전제의 문항이라 측정 상품과 맞지 않는다
