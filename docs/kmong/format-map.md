# 서비스 설명 / 제공 절차 — 서식 지정표 (수기 적용용)

> 2026-08-10 작성. 크몽 에디터에 글을 **다시 입력하지 않는다.** 이미 들어가 있는
> 줄을 클릭해 `글자 크기 선택` 드롭다운에서 등급만 지정하는 용도의 표다.

## 왜 서식이 계속 깨졌나 (원인 확정)

크몽 서비스 설명 에디터 툴바에는 **제목 버튼이 없다.** 실측한 툴바 구성:

```
글자 크기 선택 | Bold | Italic | Underline | Align left/center/right/justify
```

제목은 `글자 크기 선택` 드롭다운 안에 **대제목 / 소제목 / 본문 / 주석** 4단계로만
존재한다. 마크다운 단축키(`## `)로 만든 h2/h3는 에디터에서는 잠깐 먹지만
크몽 저장 스키마에 없는 태그라 **저장 시 전부 `<p>`로 평탄화된다.**

2026-08-10 현재 저장된 상태를 DOM으로 확인한 결과 — 서비스 설명 57개 블록,
제공 절차 16개 블록이 **전부 `P`**. 굵게(`<strong>`)는 그대로 살아 있다.

즉 자동 입력이 문제가 아니라 **h2/h3 자체가 이 필드에서 살아남지 못한다.**
드롭다운으로 지정한 등급은 크몽 자체 서식이므로 저장에 남는다.

## 적용 방법

1. 대상 줄에 커서를 놓는다 (줄 전체를 드래그할 필요 없음)
2. 툴바 맨 왼쪽 `글자 크기 선택` 클릭
3. 아래 표의 등급 선택
4. 표 전부 끝낸 뒤 **`임시 저장하기` 한 번** — 저장 전에 새로고침하면 날아간다
5. 저장 후 새로고침해서 등급이 남아 있는지 눈으로 확인

굵게(`**`) 처리는 이미 살아 있으니 손대지 않는다.

## B. 서비스 제공 절차

**먼저 고칠 것**: 첫 줄이 `진행 절차1단계. 발주 정보 전달`로 **두 줄이 붙어 있다.**
`진행 절차` 뒤에 커서를 놓고 Enter로 분리한다.

## 검증

`임시 저장하기` 후 새로고침하고, 대제목/소제목이 그대로면 성공이다.
그래도 평탄화되면 그때는 이 필드가 등급 자체를 저장하지 않는다는 뜻이므로,
제목 줄을 **굵게 + 앞뒤 빈 줄**로만 구분하는 방식으로 간다 (굵게는 저장에 남는 것을
이미 확인했다).
